# مصفوفة المخاطر وطرق الوقاية والاحتواء (Risk Management Matrix)
## نظام إدارة مخازن وتجارة مواد البناء (ERP)

---

| المعرف | الخطر التشغيلي أو التقني | مستوى الأثر | الاحتمالية | استراتيجية الوقاية والحل المعماري المعتمد |
| :--- | :--- | :--- | :--- | :--- |
| **RSK-01** | **تغير سعر السوق اليوم يغير تكلفة أو ربح فاتورة قديمة** | حرج جداً (P0) | مرتفع | حفظ سعر البيع وتكلفة البضاعة المباعة وقت الاعتماد كـ Snapshot ثابت لا يمسه أي تحديث لأسعار اليوم، وفصل مؤشر الاستبدال الإداري في حقل منفصل. |
| **RSK-02** | **انقطاع الاتصال أو تكرار الإرسال ينشئ فواتير مكررة** | عالي (P1) | متوسط | استخدام مفاتيح عدم التكرار (Idempotency Keys) وفرض قيد فريد (Unique Constraint) على رقم الفاتورة والعمليات الحساسة. |
| **RSK-03** | **تخريب البيانات عبر استيراد ملف Excel غير سليم** | عالي (P1) | مرتفع | منع الاستيراد المباشر؛ فرض دورة (معاينة ← مطابقة أعمدة ← كشف تكرار ← Dry Run محاكاة ← تأكيد صريح واستيراد ذري مع تقرير أخطاء). |
| **RSK-04** | **المخزون السالب يفسد حسابات التكلفة (COGS)** | عالي (P1) | متوسط | التحقق من الرصيد المتاح داخل الـ DB Transaction ومنع الاعتماد إذا كانت الكمية سالبة، إلا بموافقة إدارية استثنائية مسجلة. |
| **RSK-05** | **تلاعب موظف أو حذف فاتورة بعد اعتمادها** | حرج (P0) | متوسط | منع الحذف النهائي تماماً (No Hard Deletes). الحركات السابقة تُعكس بمستند مرتبط مع تسجيل إلزامي في سجل التدقيق غير القابل للتعديل (`audit_logs`). |
| **RSK-06** | **تجاوز الصلاحيات عبر استدعاء API أو Supabase مباشرة** | حرج (P0) | منخفض | فرض سياسات أمان الصفوف (Row Level Security - RLS) على مستوى قاعدة البيانات مع فحص خادمي موازٍ للجلسة والصلاحية. |
| **RSK-07** | **تشتت التكاليف الإضافية (نولون الشاحنات ومشال الأسمنت)** | متوسط (P2) | مرتفع | إنشاء جدول لمصاريف التوريد وتوزيعها آلياً على تكلفة الوحدة في شحنة الشراء حسب الوزن أو القيمة قبل اعتماد إذن الاستلام. |
| **RSK-08** | **فقدان مستندات تاريخية أو بيانات المعاملات عبر 10 سنوات** | حرج (P0) | منخفض | تشغيل خطة نسخ احتياطي مستقلة لقاعدة البيانات والملفات السحابية خارج المنصة الأساسية، مع اختبار استعادة فعلي دوري. |
| **RSK-09** | **أخطاء تقريب المبالغ والكميات الناتجة عن Float في JS** | عالي (P1) | مرتفع | منع استخدام Floating-point، واعتماد PostgreSQL `NUMERIC` بدقة محددة (15,2 للمال، 15,3 للكميات، 18,6 لمعاملات التحويل). |
| **RSK-10** | **اختلاط المخزون التالف بالمخزون الصالح عند المرتجعات** | متوسط (P2) | مرتفع | تخصيص مخزن عزل/توالف منفصل في جدول `warehouses` (`is_scrap_yard = true`) لتوجيه البضاعة المعيبة إليه آلياً. |
